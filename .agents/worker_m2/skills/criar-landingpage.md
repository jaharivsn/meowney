# Criar Landing Page de Alta Conversão & Anti-AI-Slop

Metodologia de conversão (Pedro Sobral Live 390 + Lapa.ninja SaaS benchmarks) + diretrizes de design.

## Estrutura Recomendada
1. Hero Section (headline, sub-headline, CTA principal + CTA secundário, trust badge, mockup real)
2. Prova Social (depoimentos de usuários reais com cards em grid balanceado)
3. Recurso / Benefícios (visuais em zigue-zague + grid de benefícios)
4. Tabela de Preços (planos ancorados com badges e CTAs)
5. FAQ (accordion acessível para quebra de objeções)
6. Footer (links institucionais e suporte)

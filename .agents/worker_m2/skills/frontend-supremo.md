# Frontend Supremo

Skill definitiva de frontend. Produz interfaces production-grade, distintas e memoráveis — nunca genéricas. Combina filosofia anti-slop, sistema de estilos de design, regras técnicas priorizadas, comandos de refinamento, ferramentas de detecção e busca por domínio.

## Absolute Bans
- Side-stripe borders (`border-left > 1px`)
- Gradient text (`background-clip: text`)
- Glassmorphism padrão
- Hero-metric template
- Identical card grids
- Eyebrow uppercase em toda seção
- Numbered markers (01/02/03)
- Ghost-card
- Cream/sand/beige body bg
- Hand-drawn SVG illustrations
- Decorative grid backgrounds

## Key Guidelines
- Accessibility: Contrast 4.5:1, Alt text, Keyboard nav, aria-hidden="true" on decorative icons, aria-expanded/aria-controls on accordions.
- Touch & Interaction: Min 44x44px target sizes.
- Typography: Nunito Sans for headings, Plus Jakarta Sans for body text.
